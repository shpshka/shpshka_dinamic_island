# shpshka app

Музыкальная панель для MacBook. Наведите курсор на вырез камеры, чтобы увидеть текущий трек, поставить музыку на паузу или переключить песню. Когда курсор уходит, панель сворачивается. На дисплее без выреза панель появляется по центру верхней кромки.

### Установка

1. Скачайте [shpshka-app.dmg](https://github.com/shpshka/shpshka_dinamic_island/releases/latest/download/shpshka-app.dmg).
2. Откройте образ и перетащите **shpshka app** в **Applications**. Запустите приложение из «Программ».
3. Для автоматического запуска нажмите ноту в строке меню и включите **Запускать при входе**.

Сборка подходит для Apple Silicon и Intel с macOS 13 и новее. У неё локальная подпись без нотариального заверения Apple. Если macOS не может проверить разработчика и вы доверяете источнику, после попытки запуска откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. [Инструкция Apple](https://support.apple.com/en-us/102445)

### Музыка

Включите музыку на Mac. На macOS 14.2 и новее остров определяет приложение с активным аудиовыходом. Для настольных Spotify и «Музыки» он показывает название, исполнителя и обложку, когда плеер их предоставляет. Цвет индикатора и кнопки воспроизведения берётся из обложки. Для управления плеером при первом использовании нажмите **Подключить** и разрешите автоматизацию в macOS. На macOS 13–14.1 доступно автоматическое переключение между Spotify и «Музыкой».

Для музыки в Safari и поддерживаемых браузерах на Chromium нажмите **Подключить браузер**. Чтение данных плеера вкладки требует разрешения macOS и включённой в браузере опции «Разрешить JavaScript из событий Apple». Если у приложения доступна только информация об аудиовыходе, остров показывает его имя. Определение источника звука работает без записи системного звука или микрофона.

Нажмите **Текст**. Встроенные слова открываются сразу. Если их нет, пока раздел открыт, остров автоматически ищет слова текущего трека в LRCLIB по названию и исполнителю, с учётом альбома и длительности при наличии. Найденный текст можно прокрутить и скопировать. Сервис располагает текстами только для части треков. [Документация LRCLIB](https://lrclib.net/docs)

Кнопка с булавкой оставляет остров открытым, в том числе с текстом песни. Повторное нажатие возвращает сворачивание при уходе курсора. В меню с нотой есть **Таймер сна** на 15, 30 или 60 минут. Он ставит активный трек на паузу, если плеер поддерживает управление. Там же можно скопировать название трека и открыть Карты.

### Разделы острова

- **Календарь.** Мини-календарь показывает месяц целиком. Стрелки листают месяцы, а кнопка **Сегодня** возвращает к текущей дате. Чтобы под сеткой появились события, разрешите доступ к календарям и нажмите на нужный день.
- **Уведомления.** Остров выводит короткую карточку у выреза и хранит до 25 последних событий в памяти до завершения приложения. Чтобы видеть доступные баннеры других приложений, включите **Баннеры приложений macOS** и дайте shpshka app доступ в **Конфиденциальность и безопасность → Универсальный доступ**. Отображение зависит от того, какой баннер и текст macOS показывает в момент получения. Отключить эту функцию и очистить список можно в той же вкладке.
- **Bluetooth.** После разрешения во вкладке видны подключённые устройства. Рядом с названием показан заряд в процентах, если он доступен в macOS. Для наушников могут отображаться отдельные значения левого и правого наушника и футляра. Приложение запрашивает заряд, пока вкладка открыта. О подключении и отключении приходит уведомление. Для Bluetooth LE список ограничен устройствами, которые macOS возвращает для поддерживаемых сервисов. Шестерёнка открывает системные настройки Bluetooth.

### Сборка

Для запуска нужна macOS 13 или новее. Для сборки из исходников нужны Swift 5.9 или новее и macOS SDK. Выполните в папке проекта:

```sh
./build.sh
open "dist/shpshka app.app"
```

Скрипт собирает release-версию для Apple Silicon и Intel, упаковывает её в dist/shpshka-app.dmg и подписывает её локальной ad hoc подписью. Разрешение на управление плеером можно проверить в **Системные настройки → Конфиденциальность и безопасность → Автоматизация**.
